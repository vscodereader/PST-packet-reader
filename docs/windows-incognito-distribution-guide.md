# Windows 시크릿 Chrome 배포 사용 가이드

날짜: 2026-05-28

## 이 문서의 목적

이 문서는 배포받은 Windows 사용자가 네이버 증권 토론 자동 입력 기능을 사용할 때 필요한 흐름을 설명한다.

개발 중에는 WSL Ubuntu, PowerShell, Chrome DevTools host, Chrome DevTools 포트 같은 값을 직접 만졌지만, 배포판 사용자에게는 이런 값을 보여주지 않는다.

배포판 기준 사용자는 아래만 알면 된다.

1. 프로그램을 실행한다.
2. `시크릿 Chrome 열기`를 누른다.
3. 열린 시크릿 Chrome에서 네이버 로그인을 완료한다.
4. CSV 파일을 가져온다.
5. 종목, 글쓰기/댓글쓰기, 작성 개수, 선택 방식을 고른다.
6. `설정 저장`을 누른다.
7. `실행`을 누른다.

## 왜 시크릿 Chrome을 쓰는가

일반 Chrome을 그대로 자동화하면 사용자가 평소에 쓰던 브라우저 탭, 쿠키, 로그인 상태와 섞일 수 있다.

그래서 배포판에서는 일반 Chrome 대신 자동화용 시크릿 Chrome을 사용한다.

프로그램의 `시크릿 Chrome 열기` 버튼은 Chrome을 아래 방식으로 실행한다.

```text
시크릿 모드
자동화 포트 9222
별도 임시 Chrome 프로필
네이버 첫 화면
```

사용자는 열린 시크릿 Chrome에서 네이버 로그인을 직접 완료해야 한다.

2차 인증이 있으면 2차 인증까지 직접 완료해야 한다.

## IP와 포트는 사용자가 몰라도 된다

개발 중에는 `127.0.0.1`, `172.24.32.1`, `9222`, `9223` 같은 값을 직접 확인했다.

배포판에서는 사용자가 이 값을 입력하지 않는다.

Windows 배포판은 내부적으로 아래 값만 사용한다.

```text
host: 127.0.0.1
port: 9222
```

`127.0.0.1`은 현재 사용자 본인의 컴퓨터를 뜻한다.

그래서 A 사용자 컴퓨터에서도 `127.0.0.1`은 A 사용자 컴퓨터이고, B 사용자 컴퓨터에서도 `127.0.0.1`은 B 사용자 컴퓨터다.

즉 사람마다 IP가 바뀌어도 문제가 생기지 않는다.

`9222`는 프로그램이 시크릿 Chrome을 조작하기 위해 여는 약속된 통로다.

프로그램이 Chrome을 `9222`로 열고 다시 같은 `9222`로 접속하므로 사용자는 포트가 무엇인지 알 필요가 없다.

## CSV 파일 형식

CSV 파일의 첫 번째 행은 헤더다.

첫 번째 행에는 아래 이름이 들어간다.

```csv
제목,내용,댓글내용
```

두 번째 행부터 실제 사용할 문구를 넣는다.

예시:

```csv
제목,내용,댓글내용
첫 번째 제목,첫 번째 본문,첫 번째 댓글
두 번째 제목,두 번째 본문,두 번째 댓글
세 번째 제목,세 번째 본문,세 번째 댓글
```

프로그램은 첫 번째 행의 `제목`, `내용`, `댓글내용` 자체는 가져오지 않는다.

두 번째 행부터 빈 값을 제외하고 가져온다.

## 텍스트창에서 글 수정하는 법

CSV 파일을 가져오면 제목, 내용, 댓글 내용 텍스트창에 값이 들어온다.

여러 항목은 아래처럼 `---` 줄로 구분된다.

```text
첫 번째 제목
---
두 번째 제목
---
세 번째 제목
```

수정할 때는 아래 규칙을 지켜야 한다.

- `---` 줄은 절대 지우지 않는다.
- `---` 줄의 글자도 바꾸지 않는다.
- 수정하고 싶은 문장만 드래그해서 고친다.
- 항목 사이에 엔터를 추가하지 않는다.
- 수정이 끝나면 `설정 저장`을 누른다.

잘못된 예:

```text
첫 번째 제목

---
두 번째 제목
```

항목 사이에 빈 줄이 들어가면 의도와 다르게 처리될 수 있다.

좋은 예:

```text
첫 번째 제목 수정본
---
두 번째 제목
```

## 글쓰기와 댓글쓰기 선택

글쓰기만 하려면 `글쓰기`만 체크한다.

댓글쓰기만 하려면 `댓글쓰기`만 체크한다.

둘 다 실행하려면 둘 다 체크한다.

아무것도 체크하지 않고 실행하면 프로그램은 행동을 선택하라고 알려준다.

## 랜덤, 순차, 1개만

제목, 내용, 댓글내용마다 선택 방식이 있다.

랜덤:

- 여러 항목 중 하나를 무작위로 사용한다.

순차:

- 첫 번째 실행에는 첫 번째 항목을 사용한다.
- 두 번째 실행에는 두 번째 항목을 사용한다.
- 작성 개수보다 항목 수가 적으면 다시 처음 항목부터 순환한다.

1개만:

- 항목이 정확히 하나일 때만 사용할 수 있다.
- 항목이 여러 개면 선택할 수 없다.

## 작성 개수

작성 개수는 `3개` 또는 `5개` 중 하나를 고른다.

글쓰기 기준으로 한 번의 작성은 아래까지 포함한다.

```text
글 작성
등록하기
새로고침
```

댓글쓰기 기준으로 한 번의 작성은 아래까지 포함한다.

```text
댓글 작성
Enter
새로고침
```

각 작성 사이에는 1분 대기한다.

## 배포 시 주의사항

이 프로그램은 네이버 화면과 네이버 API에 의존한다.

따라서 아래 상황에서는 수정이 필요할 수 있다.

- 네이버가 API 주소를 바꾸는 경우
- 네이버가 요청 파라미터를 바꾸는 경우
- 네이버가 자동화 탐지를 강화하는 경우
- Chrome 설치 경로가 일반적이지 않은 경우
- 사용자가 시크릿 Chrome에서 로그인을 완료하지 않은 경우

또한 자동 글쓰기/댓글쓰기는 서비스 정책과 계정 제한 위험이 있을 수 있다.

이 부분은 기술 구현과 별개로 운영 정책 확인이 필요하다.
