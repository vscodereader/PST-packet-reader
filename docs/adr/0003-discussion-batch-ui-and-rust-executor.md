# 0003. CSV 기반 토론 batch UI와 Rust 실행기 분리

날짜: 2026-05-28

## 상태

Accepted

## 배경

기존 CLI는 PowerShell에서 제목과 내용을 직접 입력한 뒤 한 번씩 실행하는 구조였다. 이 방식은 빠른 검증에는 좋지만, 실제 작업자가 여러 제목, 여러 본문, 여러 댓글 후보를 CSV로 가져와 저장하고 실행하기 어렵다.

추가 요구사항은 다음과 같다.

- 화면에서 종목을 검색하거나 목록에서 선택할 수 있어야 한다.
- 선택한 종목은 종목명, 6자리 종목코드, 토론방 링크를 확인할 수 있어야 한다.
- CSV 파일을 반드시 가져와야 실행할 수 있어야 한다.
- CSV 첫 행은 `제목`, `내용`, `댓글내용` 헤더이고, 실제 데이터는 2행부터 사용해야 한다.
- 글쓰기와 댓글쓰기를 체크박스로 선택해야 한다.
- 아무 행동도 선택하지 않으면 "행동을 선택하세요" 오류와 빨간 테두리를 보여줘야 한다.
- 제목, 내용, 댓글내용은 각각 `랜덤`, `순차`, `1개만` 선택 모드를 가져야 한다.
- `1개만`은 값이 정확히 하나일 때만 선택할 수 있어야 한다.
- 실행 개수는 `3개` 또는 `5개` 중 하나로 선택해야 한다.
- 한 번 등록한 뒤 다음 등록까지 1분 대기해야 한다.
- 실제 등록은 프론트 JavaScript가 아니라 Rust 쪽 함수가 수행해야 한다.

## 결정

화면은 `StockBatchPanel` React 컴포넌트로 추가하되, 핵심 데이터 처리와 실행은 Tauri command를 통해 Rust에서 처리한다.

### 프론트의 책임

- 파일 선택 UI 제공
- 종목 검색어 입력 UI 제공
- 선택된 종목 chip 표시
- 글쓰기/댓글쓰기 체크박스 표시
- 제목/내용/댓글내용 텍스트 수정 UI 제공
- `랜덤`, `순차`, `1개만` 선택 UI 제공
- `3개`, `5개` 실행 개수 선택 UI 제공
- 저장/실행 버튼 제공

프론트는 사용자가 값을 입력하고 확인할 수 있게 하는 역할만 담당한다.

### Rust의 책임

- CSV 문자열 파싱
- 헤더 행 제외
- 빈 값 제외
- 종목 목록 API 조회
- 종목 후보 dedupe
- batch 설정 검증
- 제목/내용/댓글내용 선택 모드 적용
- 글쓰기/댓글쓰기 실행 루프
- 등록 간 1분 대기
- 기존 패킷 기반 글쓰기/댓글쓰기 함수 호출

관련 Rust 파일은 `src-tauri/src/discussion_batch.rs`다.

## Tauri command

새로 추가한 command는 다음과 같다.

- `parse_template_csv`
  - CSV 문자열을 받아 `제목`, `내용`, `댓글내용` 목록으로 분리한다.
- `search_stocks`
  - 네이버 증권 공개 API를 호출해서 종목명, 종목코드, 토론방 링크 후보를 가져온다.
- `run_naver_discussion_batch`
  - 저장된 batch 설정을 검증하고 기존 패킷 기반 자동화 함수들을 반복 실행한다.

## 패킷 기반 함수와의 관계

batch UI는 기존 패킷 기반 함수 위에 올라가는 입력/실행 관리 계층이다. 실제 글쓰기와 댓글 등록은 계속 아래 함수들이 수행한다.

- `NaverPacketClient::read_login_profile`
- `NaverPacketClient::submit_post`
- `NaverPacketClient::submit_comment`
- `NaverPacketClient::select_random_discussion_post`
- `NaverPacketClient::ensure_profile_intro_setup`

사용자가 UI에서 직접 종목을 선택하면 랜덤 종목 선택 대신 해당 종목의 토론방 링크를 Rust 요청에 전달한다. 이렇게 하면 랜덤 API가 같은 종목을 반복해서 고르는 문제를 피하고, 작업자가 의도한 종목에 대해 실행할 수 있다.

## 결과

- CLI는 기존 검증 용도로 유지한다.
- 새 batch UI는 프로젝트 첫 화면에 추가한다.
- 기존 제목/내용 저장 UI는 제거하지 않는다.
- CSV parsing, stock search, 반복 실행은 Rust에 둔다.
- 등록 동작은 기존 패킷 기반 Rust 함수로 계속 수행한다.

## 제한

- 현재 파일 가져오기는 CSV UTF-8 파일을 기준으로 한다. Excel `.xlsx` 파일은 Excel에서 `CSV UTF-8`로 저장한 뒤 가져오는 방식으로 사용한다.
- Chrome 로그인과 2차 인증은 사용자가 직접 완료해야 한다.
- Chrome DevTools host/port는 현재 WSL 환경에서 `172.24.32.1:9223`을 기본값으로 둔다.
- 실제 서비스 정책과 계정 제한 위험은 별도로 확인해야 한다.
