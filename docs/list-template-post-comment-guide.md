# 목록형 CSV 템플릿과 글쓰기+댓글쓰기 실행 방식

날짜: 2026-05-28

## 목적

이 문서는 CSV 기반 네이버 증권 토론 자동 입력 화면의 최신 동작을 설명한다.

기존에는 제목, 내용, 댓글내용을 하나의 텍스트창에 넣고 `---`로 구분했다.

이제는 일반 사용자가 헷갈리지 않도록 CSV 항목을 목록형으로 보여준다.

또한 글쓰기와 댓글쓰기를 같이 선택했을 때 댓글 기준을 명확하게 바꿨다.

글쓰기와 댓글쓰기를 같이 선택하면 댓글은 랜덤 글이 아니라 방금 작성한 글에 작성된다.

## CSV 파일 형식

CSV 첫 행은 헤더다.

```csv
제목,내용,댓글내용
```

두 번째 행부터 실제 사용할 값을 입력한다.

예:

```csv
제목,내용,댓글내용
이게되네 ㅋㅋㅋ,난 탈출이다,지금이니?
뭣,두 번째 본문,두 번째 댓글
세 번째 제목,세 번째 본문,세 번째 댓글
```

프로그램은 첫 행의 `제목`, `내용`, `댓글내용`은 가져오지 않는다.

두 번째 행부터 빈 값을 제외하고 가져온다.

## 목록형 표시 방식

CSV를 가져오면 제목, 내용, 댓글내용은 각각 목록으로 표시된다.

예를 들어 제목이 두 개라면 제목 영역은 아래처럼 보인다.

```text
1  이게되네 ㅋㅋㅋ
2  뭣
```

이전처럼 `---` 구분선은 보이지 않는다.

## 항목 선택 방식

목록 항목을 한 번 클릭하면 선택된다.

선택된 항목을 다시 클릭하면 선택 해제된다.

선택된 항목만 실행 대상이 된다.

예를 들어 제목 목록에 아래 3개가 있다고 가정한다.

```text
1  제목 A
2  제목 B
3  제목 C
```

이 중 제목 A와 제목 C만 선택하면 랜덤/순차/1개만은 제목 A와 제목 C만 대상으로 동작한다.

## 항목 수정 방식

목록 항목을 더블클릭하면 수정 모드가 열린다.

수정 후 목록 안의 `저장`을 누르면 해당 항목 값이 바뀐다.

`취소`를 누르면 기존 값이 유지된다.

수정한 뒤 전체 실행 설정에 반영하려면 `설정 저장`을 누른다.

## 한 번에 보이는 항목 개수

목록은 한 번에 최대 5개 정도만 보이도록 높이를 제한했다.

항목이 5개보다 많으면 목록 안에서 스크롤해서 확인한다.

## 랜덤, 순차, 1개만

각 목록 아래에는 선택 방식이 있다.

랜덤:

- 선택된 항목 중 하나를 무작위로 사용한다.

순차:

- 첫 번째 실행에는 선택된 첫 번째 항목을 사용한다.
- 두 번째 실행에는 선택된 두 번째 항목을 사용한다.
- 선택된 항목보다 실행 횟수가 많으면 다시 처음 항목부터 반복한다.

1개만:

- 선택된 항목이 정확히 1개일 때만 사용할 수 있다.

## 글쓰기만 선택한 경우

글쓰기 체크박스만 선택하면 글쓰기 설정 영역만 보인다.

보이는 항목:

```text
제목 목록
내용 목록
제목 선택 방식
내용 선택 방식
작성 개수
설정 저장
실행
```

실행하면 Rust 패킷 함수가 글쓰기 form 패킷으로 txId를 받고, 글쓰기 add 패킷으로 글을 등록한다.

## 댓글쓰기만 선택한 경우

댓글쓰기 체크박스만 선택하면 댓글쓰기 설정 영역만 보인다.

보이는 항목:

```text
댓글 내용 목록
댓글 선택 방식
작성 개수
설정 저장
실행
```

실행하면 Rust 패킷 함수가 선택한 종목의 토론글 목록 API를 호출해서 댓글을 달 게시글을 고른다.

그 다음 cbox token 패킷과 댓글 create 패킷으로 댓글을 등록한다.

## 글쓰기와 댓글쓰기를 같이 선택한 경우

글쓰기와 댓글쓰기를 같이 선택하면 두 설정 영역이 모두 보인다.

이때 실행 기준은 다음과 같다.

```text
글 먼저 작성
방금 작성한 글에 댓글 작성
```

구체적인 Rust 패킷 흐름:

```text
1. 선택한 제목/내용으로 글쓰기 form 패킷 요청
2. txId 수신
3. 글쓰기 add 패킷 요청
4. add 응답에서 작성 글 ID 수신
5. 작성 글 ID로 글 URL 생성
6. 해당 글 URL 기준 댓글 token 패킷 요청
7. 댓글 create 패킷 요청
8. 화면 새로고침
```

중요한 점:

댓글을 달기 위해 프론트 화면에서 방금 쓴 글을 클릭해서 찾는 방식이 아니다.

Rust가 글쓰기 응답의 ID를 사용해 작성 글 URL을 직접 만든 뒤 댓글 패킷을 전송한다.

## 작성 개수

작성 개수는 글쓰기 또는 댓글쓰기를 선택했을 때만 보인다.

선택지는 아래 두 개다.

```text
3개
5개
```

글쓰기만 선택하면 3개 또는 5개의 글을 작성한다.

댓글쓰기만 선택하면 3개 또는 5개의 댓글을 작성한다.

글쓰기와 댓글쓰기를 같이 선택하면 3개 또는 5개의 글을 작성하고, 각각의 글에 댓글을 작성한다.

## 프론트와 Rust 역할 구분

프론트가 담당하는 것:

- CSV 파일 선택
- 목록 표시
- 항목 선택
- 더블클릭 수정 UI
- 글쓰기/댓글쓰기 체크박스 표시
- 작성 개수 선택
- 실행 버튼 제공

Rust가 담당하는 것:

- CSV 파싱
- 종목 검색 API 호출
- 네이버 로그인 쿠키 기반 패킷 클라이언트 생성
- 로그인 확인 getProfile 패킷
- 글쓰기 form/add 패킷
- 댓글 token/create 패킷
- 프로필 2222 설정 패킷
- 글쓰기+댓글쓰기 동시 선택 시 작성 글 ID 기반 댓글 대상 결정

따라서 실제 등록 작업은 프론트 DOM으로 넘기지 않고 Rust 패킷 함수에서 처리한다.
