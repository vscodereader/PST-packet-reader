# 03. 계정 분배 화면

- 설계서 근거: `설계.md` §10-3 (계정 풀 + 하위 선택 → 균등·랜덤 분배, MOVE)
- 코드: `src/admin/features/account-distribute/account-distribute.tsx`
- 상태: UI만 (더미)

## 레이아웃 — 위/아래 절반

**상단 절반 — 계정 풀**

- [계정 추가] [엑셀 가져오기] 버튼 + "총 N개 계정" 배지
- 표: 헤더 전체선택 체크박스 + 행별 체크박스 / 아이디 / 비밀번호(마스킹 ••••••)
- **최대 8행 고정 높이 + 세로 스크롤**

**하단 절반 — 연결된 하위 컴퓨터**

- **online 만 표시**, 행별 체크박스 + 컴퓨터 아이콘 + 이름 + 초록 원·IP
- **[분배하기]** 버튼: 계정 ≥1 **그리고** 하위 ≥1 선택 시 활성

## 분배 동작 (균등 + 랜덤 + MOVE)

- 선택 계정 N개를 선택 하위 M대에 **균등 분배(±1)**.
- **랜덤**: 어느 대가 +1 받을지 셔플로 무작위(예: 10개 3대 → 4·3·3, +1 받는 대 매번 달라짐).
- **MOVE**: 분배된 계정은 풀에서 **사라짐**(한 시점에 한 곳, §7).
- (데모) [분배하기] → 토스트 "계정 N개를 M대에 분배했어요 (4·3·3)" + 선택 계정이 표에서 제거.

> 실제 구현은 기존 `distributeStocksEvenly()`(`publish-helpers.ts`) 재사용 + 분배 직전 셔플 1줄. 미리보기는 동일 규칙을 자체 구현으로 시연.

## 확인 방법

`pnpm dev` → admin.html → "계정 분배". 계정 몇 개 + 하위 몇 대 체크 → [분배하기].
