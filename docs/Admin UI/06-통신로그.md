# 06. 통신 로그 화면

- 설계서 근거: `설계.md` §10-5 (감사로그 콘솔 + 내보내기), §7 감사로그, §4 상태
- 코드: `src/admin/features/comm-log/comm-log.tsx`
- 위치: 사이드바 "비밀번호 변경" 아래
- 상태: UI만 (더미 로그)

## 무엇을 보여주나

**모든 컴퓨터(하위)의 Admin↔하위 통신**을 콘솔(PowerShell/명령창 스타일)로 한 곳에서:

- `[CMD]` Admin → 하위 명령 (import_then_login_all, distribute_accounts, delete_accounts + commandId)
- `[RESULT]` 하위 → Admin 결과 (진행률·최종 집계 성공/보류/대기초과/실패)
- `[HEARTBEAT]` / `[STATE]` 하위 → 서버 (online·IP·ROTATING 등 §4)
- `[SSE]` / `[REGISTER]` 연결·끊김·재연결(새 IP)·기기등록·토큰발급

## 형식

- 한 줄 = `시각  [태그]  방향  메시지` (모노스페이스, 어두운 배경).
- 색: CMD=파랑 / 결과·성공=청록 / 실패=빨강 / 경고=노랑 / 정보=회색.
- **비밀 미노출**: PW·쿠키 안 찍음(기존 `logging.rs` 컨벤션). ID는 앞 2글자(`st****`).
- **컴퓨터 필터**: 전체 / 특정 하위 선택.

## 내보내기

- 화면 위 **[내보내기]** 버튼 → 로그를 **`.txt`** 파일로 저장.
- 웹이라 브라우저 다운로드(Blob)로 저장(§8 데스크톱 전용 호출의 웹 대체).

## 확인 방법

`pnpm dev` → admin.html → 사이드바 "통신 로그".

- 콘솔에 더미 통신 로그(명령·결과·하트비트·IP변경) 18줄.
- 상단 [내보내기]로 `comm-log.txt` 다운로드.
- 컴퓨터 필터로 특정 하위만 보기.
