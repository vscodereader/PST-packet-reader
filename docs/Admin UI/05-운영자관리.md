# 05. 운영자 관리 화면

- 설계서 근거: `설계.md` §5 (가입 승인 + 운영자 삭제, 권한 전원 동일)
- 코드: `src/admin/features/operators/operators.tsx`
- 상태: UI만 (더미)

## 구성

**가입 승인 대기**

- 신청자 목록(아이디) + [승인] / [거절]
- 승인은 **승인된 운영자 누구나** 가능(권한 차등 없음).
- (데모) 승인 → 운영자 목록으로 이동, 거절 → 제거.

**운영자 목록**

- 아이디 + 역할 배지(SuperAdmin / 일반) + [삭제]
- **삭제는 SuperAdmin 전용** 동작. **SuperAdmin 계정 자체는 삭제 불가**(버튼 비활성 "삭제 불가").
- 권한은 전원 동일 — "운영자 삭제"만 SuperAdmin 전용(§5).

## 확인 방법

`pnpm dev` → admin.html → "운영자 관리". 대기 2명 / 운영자 3명(Superadmin 포함) 더미.
