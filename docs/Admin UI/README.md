## 미리보기에서 화면 전환

`admin.html` 우상단의 **"미리보기 화면" 선택기**로 8개 화면 아무거나 바로 띄울 수 있다(실제 앱엔 없는 미리보기 전용 장치). 로그인 후 화면은 좌측 사이드바로도 이동.

## 재사용 원칙

기존 앱 UI(Mantine 9 테마·컴포넌트·토스트·아이콘)를 **그대로 재사용**한다:

- 테마/프로바이더: `src/app/providers.tsx`(`AppProviders`), `src/app/theme.ts`
- 토스트: `@mantine/notifications`의 `notifications.show({ message, color })`
- 아이콘: `src/shared/ui/icons.ts`(`Icon.copy`, `Icon.refresh` 등) + `@tabler/icons-react`
- 미리보기는 Tauri에 의존하지 않는 **독립 웹 엔트리**(`admin.html`)라 브라우저로 바로 열림.
