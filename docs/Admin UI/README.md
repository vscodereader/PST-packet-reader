# Admin UI 화면 명세 (기능별)

- 작성일: 2026-06-28 (백엔드 연결: 2026-06-30)
- 목적: `docs/설계.md`의 Admin 웹 화면을 **기능별 1파일**로 쪼개, 무엇이 어떤 화면인지 눈으로 보고 지시할 수 있게 정리.
- 상태: **화면 + 백엔드(중앙 서버 `server/`) 연결됨**. 인증·운영자·기기·계정 분배·통신로그가 실제 서버 API로 동작한다(§10). **서버가 안 떠 있는 오프라인 미리보기에서는 더미 데이터로 폴백**하므로 화면은 항상 뜬다.
  - 결과 보고 화면의 **게시 결과**는 하위 에이전트(P5, 미구현)가 보고하는 데이터라 현재는 더미 표시.
- 실제 코드: `src/admin/**`(별도 Vite 엔트리 `admin.html`) + 클라이언트 `src/admin/api.ts`. 서버는 `server/`(Rust, axum+PostgreSQL). 보는 법은 각 파일 하단 "확인 방법" + `server/README.md` 참고.

## 미리보기에서 화면 전환

`admin.html` 우상단의 **"미리보기 화면" 선택기**로 9개 화면 아무거나 바로 띄울 수 있다(실제 앱엔 없는 미리보기 전용 장치). 로그인 후 화면은 좌측 사이드바로도 이동.

## 재사용 원칙

기존 앱 UI(Mantine 9 테마·컴포넌트·토스트·아이콘)를 **그대로 재사용**한다:

- 테마/프로바이더: `src/app/providers.tsx`(`AppProviders`), `src/app/theme.ts`
- 토스트: `@mantine/notifications`의 `notifications.show({ message, color })`
- 아이콘: `src/shared/ui/icons.ts`(`Icon.copy`, `Icon.refresh` 등) + `@tabler/icons-react`
- 미리보기는 Tauri에 의존하지 않는 **독립 웹 엔트리**(`admin.html`)라 브라우저로 바로 열림.
