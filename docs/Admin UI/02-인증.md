# 02. 인증 화면 (로그인 / 회원가입 / 비밀번호 변경)

- 설계서 근거: `설계.md` §5
- 코드: `src/admin/auth/{login,signup,change-password}.tsx`
- 상태: UI만 (더미)

로그인 전 화면은 사이드바 없이 **전체화면 가운데 카드**로 렌더.

## 로그인 (`login.tsx`)

- 아이디 / 비밀번호 입력 + [로그인]
- **Enter로 로그인**: 아이디·비밀번호 칸에서 **Enter만 쳐도** 로그인(`<form>` + 버튼 `type=submit`). 버튼 클릭 불필요. (아이디 칸 자동 포커스)
- "회원가입" 링크
- 비밀번호 찾기·이메일 인증 **없음**(§5) — 안내 문구로 명시
- (데모) [로그인] → 토스트 후 기기 연결 화면으로 이동

## 회원가입 (`signup.tsx`)

- 아이디 / 비밀번호 / 비밀번호 확인 (이메일 없음)
- 안내: **가입 후 승인되어야 로그인 가능**
- [가입 신청] → 토스트 후 로그인으로

## 강제 비밀번호 변경 / 비밀번호 변경 (`change-password.tsx`)

- `forced` prop로 두 용도 겸용:
  - **forced=true**: SuperAdmin 첫 로그인(`Superadmin`/`Superadmin`) 직후 강제. 주황 경고 배너.
  - **forced=false**: 로그인 후 본인 비번 변경(사이드바 "비밀번호 변경").
- 현재 비번 / 새 비번 / 새 비번 확인 + [변경하고 다시 로그인]
- **현재 비밀번호 미리 채움**: forced=true면 현재 비번 칸에 기본값 `Superadmin`이 이미 입력돼 있어, 운영자는 **새 비번만 입력/재입력**하면 된다(매번 현재 비번 재입력 불필요). 새 비번 칸 자동 포커스.
- **Enter로 제출**: 새 비번 칸에서 **Enter만 쳐도** 변경·재로그인(`<form>` + `type=submit`).
- **변경 후 재로그인**(확정, §5) → 토스트 후 로그인으로

## 확인 방법

`pnpm dev` → http://localhost:1420/admin.html → 우상단 "미리보기 화면"에서
**로그인 / 회원가입 / 강제 비밀번호 변경** 선택.
