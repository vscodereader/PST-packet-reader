```
┌──────────────────────────────────────────────┐
│ 상단 절반 — 기기코드·서버주소 발급/복사               │

```

## 상단 절반 — 발급/복사

- **서버 주소**: 읽기 전용으로 **항상 표시**(버튼 누르기 전부터). 모든 하위 공통 값. 옆에 [복사].
- **[기기코드 발급]** 버튼: 누르면 그 아래에 **기기코드 + 만료 카운트다운** 표시 + [복사].
  - 1회용·하위 1대당 1개. 하위 여러 대면 발급도 대수만큼(§6-1).
  - (UI 단계) 클릭 시 더미 4자리 코드 생성 + 토스트 "기기코드를 발급했어요".

## 하단 절반 — 연결된 컴퓨터 현황

**각 기기 행 구성**

- **좌측**: 컴퓨터 아이콘(`IconDeviceDesktop`).
- **우측 상단**: 기기 이름(예: `하위-001`).
- **우측 하단**: 상태 텍스트 + 상태 원.
  - `connected` → 상태 원 **초록불**, 텍스트 기본색.
  - `disconnected` → 상태 원 **회색불**, 텍스트 **빨간색**.
- **행 맨 오른쪽**: **[기기 삭제] 버튼(휴지통 아이콘, 빨강)** — 그 기기의 등록을 해제(§6-4).
  - 실제로는 `DELETE /devices/{id}` → 서버가 기기표에서 줄 삭제 → 옛 기기토큰 자동 무효. 그 뒤 [기기코드 발급]으로 같은 컴퓨터를 다시 등록.
  - (UI 단계) 클릭 시 목록에서 제거 + 토스트 "OOO 기기를 삭제했어요 (등록 해제)".

**[새로고침] 버튼**

- 수동 갱신. "기기가 연결됐는데 화면이 안 바뀌는" 경우 대비 안전장치.
- (UI 단계) 클릭 시 "마지막 갱신" 시각 갱신 + 토스트.

**연결 시 자동 새로고침 + 토스트 (원칙)**

- 새 하위가 연결되면 **화면 자동 갱신** + 토스트 **"OOO 기기가 연결되었습니다."**.
- 실제 트리거: Admin이 연 `GET /admin/stream` SSE의 `{device_id, online}` 이벤트(§3·§4-1).
- (UI 단계) "데모: 기기 연결 시뮬레이션" 버튼으로 disconnected 기기 1대를 connected로 바꿔 **자동 갱신 + 토스트**를 시연.

## 확인 방법

```bash
pnpm dev            # Vite 개발 서버 (포트 1420)
```

브라우저에서 **http://localhost:1420/admin.html** 열기 → 좌측 메뉴 "기기 연결".

- 상단 [기기코드 발급] 눌러 코드 생성·복사 확인.
- 하단 [데모: 기기 연결 시뮬레이션] 눌러 토스트 + 자동 갱신 확인.
- 하단 [새로고침]으로 수동 갱신 확인.
