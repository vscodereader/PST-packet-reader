## 회귀 수정
어제까지 되던 순수 API 블로그 발행이 오늘 막힘 — 블로그 **있는** 계정(hakrell05·eunjee4714·j_scent_3sec)도 발행 실패.

### 원인 (로그·패킷 확정)
1. 발행 함수가 발행 전 `ensure_blog_exists`(SeOptions)를 **강제 게이트**로 호출 → 실패 시 발행 자체 차단. "SeOptions 실패=블로그 없음"으로 잘못 단정.
2. SeOptions 요청 referer가 틀림(`/{blogId}?Redirect=Write`) → 네이버가 "게시물이 삭제되었거나 다른 페이지로 변경되었습니다" 에러 HTML 반환 → se-auth 못 얻어 미디어(사진·링크·스티커)도 실패.

### 수정
1. **게이트 제거**: publish/publish_blocks에서 존재확인 강제호출 삭제 → 어제처럼 쿠키로 직접 RabbitWrite. 자동생성은 발행을 막지 않는 별도 커맨드로 분리.
2. **referer 실측값**: `PostWriteForm.naver?blogId={id}&Redirect=Write&redirect=Write&widgetTypeCall=true&topReferer=...&trackingCode=naver_main&directAccess=false` (패킷 그대로).
