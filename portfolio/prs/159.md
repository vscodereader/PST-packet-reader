## Summary

- 종목토론방 **종목 선택 화면**을 `m.stock.naver.com/domestic/home/priceTop/total` 모바일 페이지처럼 재디자인. 기존 `search_naver_stocks`가 데스크탑 API로 만든 **~80개 풀 안에서만** 필터링해 풀 밖 종목(KODEX 등)이 검색돼도 안 나오던 근본 문제를 해결한다.
- 신규 Rust 모듈 `src-tauri/src/forum_stocks/`가 네이버 **모바일 front-api**(카테고리 목록·토론 랭킹·🔥 활발종목·전체검색)를 호출·파싱한다. 데이터 페치는 전부 백엔드, 프론트는 렌더만.
- UI: 카테고리 **6탭**(토론·거래대금·인기 종목·상승·하락·거래량) + **KRX/NXT** 거래소 선택(딤 모달) + 🔥 활발 종목 표시 + **더보기** 페이지네이션 + **전체검색**(검색어 포함 국내 종목 전부, 80개 상한 제거).
- 기존 `search_stocks`·게시엔진·로그인·카페·밴드·큐는 **불변**. `lib.rs`에 커맨드 2개 등록 + 선택 모달 렌더 교체만 한 additive 변경이다.

Closes #157
