## Summary
- **증상**: 429(Too Many Requests)로 한 종목 실패한 계정이 직후 다른 종목들을 **정상 게시(계정 살아있음)**하는데도 그 계정이 **Error**로 분류됨. 실측 로그 2026-07-01 `jwy****`: 에코프로 429 실패 → LG전자·LS ELECTRIC·NAVER 정상 게시.
- **원인**: `is_timed_out_failure`가 429를 제외 → 429 최종 실패가 "그 밖의 실패"로 떨어져 계정이 Error(차단>대기초과>에러>대기 우선순위).
- **수정**: `is_timed_out_failure`에 429 포함 →
  - 계정 상태: 429 → **TimedOut(대기초과=재시도·계정 살아있음)**, Error 아님.
  - `is_retryable_forum_failure`(=`!blocking && timed_out`)도 429=true → 아이템 재시도(횟수·총시간 상한 내). 재시도 끝에 **진짜 차단되면 `is_blocking_failure`가 우선해 Blocked** → "최종결과로 판단"(살아있으면 대기, 차단이면 오류) 실현.
