## Summary

- PR #304(네이버 폼 자동입력)에 이어, **앱 전체 실패→알림 "자세히 보기"(백트레이스) 누락을 감사**해 남은 로그인 실패 3곳을 메운다 — 전부 `trace=None`으로 흘러 추적 불가였다.
  - `band_auth/login_flow.rs` `run`: graceful `Ok(BandLoginOutcome::Error)`(폼 못 찾음/타이핑 실패/루프 오류)에 백트레이스 부착(네이버 `login_flow`와 동일 패턴).
  - `auth/login.rs` · `band_auth/login.rs` finalize: 쿠키는 저장됐는데 유효 세션이 없는 **예기치 못한 `Error`**를 `failure()` → `failure_with_trace(..., backtrace_string())`로.
- **감사 결과 gap 아님(변경 없음)**: 카페 게시/댓글·블로그 댓글·밴드 게시·포럼 실제오류는 이미 trace 보유(`failure_trace`/`backtrace`). 비번오류/차단(BadCredentials/Blocked)은 **설계상 trace=None 유지**(예상된 실패엔 백트레이스 불필요 — `outcome.rs` 규약). cascade skip("앞선 글…건너뜀")은 파생 스킵이라 제외.
