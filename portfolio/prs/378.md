## 무엇을

계정관리 화면의 **'IP 변경' 버튼 옆에 '수동추가' 버튼**을 추가합니다. 클릭하면 실제 네이버 로그인 페이지가 **보이는 Chrome 창**으로 열리고(headed), **자동 타이핑도 ADB IP 회전도 없이** 사람이 직접 아이디/비밀번호를 입력해 로그인합니다.

로그인에 성공하면:
1. 세션 쿠키를 **자동로그인과 완전히 동일한 위치·구조**(`cookies/{loginId}.json`, payload `{accountId, savedAt, cookies}`)로 저장합니다 — 기존 `collect_naver_cookies` 수거 + `finalize` 저장을 **그대로 재사용**(저장 로직 중복 없음)하므로 수동/자동 쿠키 파일이 구조적으로 같습니다.
2. 사람이 친 **평문 ID/PW**로 계정관리에 새 행을 `status=Active(활성)`으로 자동 추가합니다.

취소 / 180초 타임아웃 / 창 닫힘이면 **아무것도 추가하지 않습니다**(프론트는 중립 토스트).

## 어떻게

- **`auth/login_flow.rs`**: `manual_add_wait` — LOGIN_URL로 이동 후 `#id`/`#pw`에 사람이 친 값을 폴링하며 마지막 비어있지 않은 값을 계속 캡처(네비게이션으로 비워지기 전 보존), 성공 판정은 자동로그인과 동일하게 `has_session_cookies`로. CDP 연속 실패(창 닫힘)/타임아웃은 취소(`Ok(None)`). 순수 헬퍼 `captured_credentials_valid` + 단위 테스트 추가.
- **`auth/login.rs`**: `finalize`를 `pub(crate)`로(중복 저장 로직 대신 재사용), 오케스트레이터 `manual_add`(headed launch → connect → wait → finalize).
- **`auth/mod.rs`**: `manual_add_account`(blocking 스레드 래퍼).
- **`lib.rs`**: `#[tauri::command] manual_add_account`를 `rotate_ip` 옆에 등록.
- **프론트**: `ipc.auth.manualAdd()` 래퍼 + 계정관리 '수동추가' 버튼(로딩 스피너, 성공 시 목록 새로고침·성공 토스트, 실패/취소 시 중립 토스트).

**기존 자동로그인 경로/동작은 변경하지 않고 추가만** 했습니다.
