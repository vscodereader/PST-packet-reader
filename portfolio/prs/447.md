## Summary
게시명령 종목토론방(글·글+댓글)에서 종목을 **자동선택**(불꽃🔥 우선 N개) 대신 **직접 고르는** 경로 추가. 종목토론방 선택 시 `종목 자동선택 | 종목 수동선택` 토글이 뜨고, 수동은 데스크톱(pstmacro) 종목선택 모달을 **공유 컴포넌트로 재사용**한다.

핵심(저위험): 자동선택은 이미 종목을 `{code,name}`으로 확정해 `assignments`로 보내므로, 수동은 `picked` 배열만 다른 방식으로 채우면 게시 파이프라인 전체가 그대로 재사용된다.

## 변경
- **Admin** `publish-command.tsx`: `ForumConfig`에 자동/수동 토글(기본 자동), `picked` 통합, 수동 시 종목선택 모달+배지.
- **공유** `src/shared/ui/stock-select-modal-view.tsx`(신규): 데스크톱 모달 UI 추출(데이터 어댑터 주입). 데스크톱 `stock-crawl-modal.tsx`는 ipc 어댑터 주입 래퍼로 축소(**무손상**), Admin `stock-select-modal.tsx`(신규)는 api 어댑터 + 1시간 마커는 `postReports`를 deviceId로 필터.
- **서버** `naver_stocks.rs`/`routes.rs`: `fetch_search_page` 이식(KOR&stock 필터) + `search()` 래퍼 + `q` 파라미터. 🔥·ETN숨김·원문캡처 부속은 기존 재사용.
- **무변경**: 게시/계정/내용변경/예약/나눠서·하위 엔진·types·댓글(URL) 경로.

## 범위
종토 **글·글+댓글만**(댓글=URL 기반, pstmacro가 종목선택 면제 — 대상 아님).
