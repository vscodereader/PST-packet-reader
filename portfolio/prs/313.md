## 배경
#312(위장 헤더)로 1·2단계(groupId 추출·cbox 토큰)는 통과하게 됐다. 그런데 3단계 댓글 등록에서 실제 앱 실행 시 `블로그 댓글 등록에 실패했습니다(네이버가 성공을 반환하지 않음)` (백트레이스 `comment_client.rs` `post_blog_comment`)로 막힘 — 헤더 수정이 먹혀 흐름이 진짜 등록 요청까지 도달했다는 뜻.

문제: 현재 에러는 "성공 안 줌"만 알려주고 **네이버가 준 실제 거절 사유(code/message)** 를 안 보여줘 원인(금칙어·중복·이웃공개 제한·스팸차단 등)을 알 수 없다.

## 변경
- `create_failure_detail(body)` 추가 — 실패 응답 JSON의 `success`/`code`/`message`를 뽑아 에러 메시지에 싣는다. JSON이 아니면(봇차단 HTML 등) 길이+스니펫(`response_diagnostic`)으로 폴백. 본문엔 쿠키가 없어 자격 증명 노출 없음(순수 함수).
- `post_blog_comment` 실패 경로가 이 detail을 포함하도록 수정.

## 테스트
- `cargo test --lib naver_blog` → 33 passed (`create_failure_detail` code/message 추출 + 비JSON 폴백 포함).
- 목적: 다음 실행 때 에러에 `code=..., message=...`가 찍혀 거절 사유를 즉시 확인 → 정확한 후속 수정.
