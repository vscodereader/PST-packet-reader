## 무엇을
종목토론방 게시 시, **실명인증(NI)을 안 한 계정**은 프로필 생성 POST(`/api/community/profile/users`)가 **500 `{"message":"Failed to create profile user"}`**로 막힙니다(2026-07-03 실기기 실측 `lee****`). 지금은 실패 사유가 원문 HTTP 오류로만 떠서 원인 파악이 어렵습니다.

## 변경
프로필 상태 응답의 **`isNiConnected=false`**(실명인증 미연결)일 때 프로필 생성이 실패하면, 게시 실패 사유를 **"실명인증이 되지 않았습니다"**로 바꿉니다.
- 흐름은 **그대로**(생성 시도 자체는 유지), 사유 메시지만 명확화.
- 네이버 원문(status=500, body…)은 사유 뒤에 **그대로 보존**.

## 범위
- `src-tauri/src/naver_automation/packet_client.rs` 한 파일, 프로필 생성 None 분기의 `.map_err`만 추가(16+/1-).
- 컴파일 확인 완료(cargo xwin check, windows-msvc). 게시 로직·성공 경로 무변경.

> 참고: 이 수정은 원래 Admin 원격제어 브랜치(#324)에 섞여 있던 **일반 게시엔진 코드**라, 별도 브랜치로 떼어 master에 먼저 반영합니다.
