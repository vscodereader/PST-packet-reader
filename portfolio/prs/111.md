## PR 본문 원문

## 문제

`[ADB]`(IP 로테이션)·`[LOGIN]`(로그인 폼)·`[CHROME]`(Chrome 생명주기) 상태 로그가 `eprintln!`(stderr)이라 `pnpm tauri dev` 콘솔에서만 보였다. **콘솔이 없는 릴리즈 exe**(`windows_subsystem = "windows"`)에선 어디에도 남지 않아, IP가 바뀌었는지·로그인이 됐는지 사용자가 확인할 방법이 없었다.

## 변경

- `auth/{adb,chrome,login_flow,mod}.rs`의 상태 `eprintln!` 16개 → `tracing::info!`. 메시지 텍스트는 그대로(`[ADB] ✓ IP 변경됨!` 등).
- `logging.rs`: 기존 파일 레이어에 더해 **stderr 콘솔 레이어** 추가. → dev 터미널에선 그대로 보이고, exe에선 **파일 로그**에 남는다.

## 결과

- **dev**: 터미널 출력 동일하게 유지.
- **exe**: 상태가 `%APPDATA%\com.beyondsoft.pstmacro\logs\pstmacro.log.<날짜>`에 기록 → `Get-Content ... -Wait`로 실시간 확인 가능.
