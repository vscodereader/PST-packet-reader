## 링크 발행 실패 (로그로 확정)
링크 낀 글만 RabbitWrite `{"errorCode":"not acceptable"}`, 링크 없는 글은 성공. 원인: oglink 컴포넌트 `link`에 사용자 입력 원본을 넣었는데, 실제로는 `oglinkSign`이 **서명한 정규화 URL**(oglink 응답 `oglink.url`, 예 `http://www.naver.com`)을 넣어야 함 → 불일치로 거부.
- `OglinkMeta.url` 추가(응답 정규화 URL), `createOglinkBlock`이 이 값을 link로 사용.
- og태그 없는 URL(summary 없음)에도 파싱 견고화(링크 삽입 가능), link 스킴 정규화.

## 발행 결과 알림창 기록 (종토처럼)
- 발행 성공/실패를 `ipc.activity.append`로 **알림창**에 기록(토스트만 뜨던 문제).
- 시스템 알림 행이 텍스트 속 URL을 **클릭 가능한 링크**로 렌더(SystemTitle).
