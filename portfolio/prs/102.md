## Summary

네이버 CDP 로그인에서 **보안문자(ncaptcha)** 가 뜨던 문제를, 패킷·안티봇 번들(`wtm.pstatic.net`) 분석으로 원인을 특정하고 단계적으로 제거했다. **실제 계정 로그인에서 캡차 없이 성공을 확인**(2026-06-05, headed)했다. ncaptcha는 점수형 봇탐지라 단일 원인이 아니라 여러 신호의 합이며, 아래 네 축을 모두 낮춰야 통과한다. 전부 백엔드(`auth/*`)이고 프론트는 미관여이며, 기존 로그인 흐름(폼 완전 로딩 대기·2초 페이싱·신호 분류·2회 연속 확정 latch)은 누락·삭제 없이 보존했다.

**1. 키 입력 사실감** (`149510f`)
- 패킷 분석상 성공 로그인은 요청 쿠키가 `NNB` 하나뿐·`bvsd`도 빈 채로 캡차 없이 즉시 성공 → 원인은 기기신뢰·행위데이터·쿠키가 **아님**.
- `Input.dispatchKeyEvent`에 실제 US 키보드와 동일한 `code`·`windowsVirtualKeyCode`·`nativeVirtualKeyCode`를 채움(기존 `keyCode === 0` → `default_ecc.js` keydown 암호화 훅이 합성 입력으로 판정). Shift 모디파이어를 대문자뿐 아니라 기호(`!@#$` 등)에도 일반화. 문자→키 매핑은 순수 함수 `key_info`로 분리해 단위 테스트.

**2. 정적 지문 — `navigator.webdriver`** (`0bda79e` → `066fd9b`)
- 안티봇 번들의 `getWebdriver()`가 `navigator.webdriver`를 읽는다. 일반(비자동화) 크롬은 `false`를 보고한다.
- `chrome.rs`: 실행 플래그 `--disable-blink-features=AutomationControlled` 추가(`webdriver=true` + "자동화 제어 중" 신호 차단).
- `login_flow.rs`: navigate 전에 `Page.addScriptToEvaluateOnNewDocument`로 `navigator.webdriver`를 가린다. 최초 `undefined`(필드 없음)로 마스킹했으나 이는 오히려 일반 크롬과 달라 역효과여서, 정확히 **`false`** 로 정정. headed/headless 모두 best-effort(CDP 실패해도 로그인은 진행).

**3. 행동 위장** (`f9735d9`, ADR-0010 Phase 1)
- 포커스·로그인 버튼을 JS `.focus()/.click()` 대신 `Input.dispatchMouseEvent` 좌표 클릭(진짜 mouse 이벤트). 좌표를 못 구하면 기존 JS 방식으로 폴백(클릭 실패가 로그인을 막지 않게).
- 글자 사이에 사람 같은 랜덤 지연(60~180ms). 시드+인덱스 순수 함수 `type_delay_ms`(splitmix64 혼합)로 분리해 단위 테스트 — 범위 clamp로 "초 단위 지연"을 원천 차단, 인덱스/시드별 변동·결정성 검증.

**4. CDP 자기탐지 차단** (`dfd9182`, ADR-0010 Phase 3)
- wtm 번들에 `Error.stack` 게터 + `Symbol.toPrimitive` + console 직렬화 트랩 시그니처가 실재 → `webdriver`·타이핑·마우스와 **무관하게** "DevTools(CDP)로 제어 중"인지 자체를 잡아 곧장 캡차를 띄우는 가장 강한 신호다.
- 그 누출의 원천인 `Runtime.enable`을 로그인에선 켜지 않는다. 로그인 전용 `enable_page_only()`(Page.enable만) 추가. 로그인 시퀀스는 `Runtime.evaluate`·`Network.getCookies`·`Input.*`·`Page.navigate`·`addScriptToEvaluateOnNewDocument`만 쓰며 이들은 `Runtime.enable` 없이 동작한다. 다운스트림 글쓰기/댓글의 `enable()`은 이벤트가 필요할 수 있어 그대로 둔다.

ADR-0009(CDP 로그인)의 봇탐지 완화책("fresh 컨텍스트 + 실제 키 이벤트 + `addScriptToEvaluateOnNewDocument` 핑거프린트 보정")을 강화하는 방향이며, 스텔스 설계 전반은 **ADR-0010(#106)** 에 기록한다.

Closes #100

### dfd9182aef0e419b2474846fa6a29905ca035c5d

fix(auth): don't enable Runtime domain on login (avoid CDP detection)

네이버 봇탐지 번들(wtm.pstatic.net)에 Error.stack 게터 + Symbol.toPrimitive +
console 직렬화 트랩 시그니처가 실재한다 — 이는 navigator.webdriver·타이핑·마우스와
