# Summary

완료 알림에서 **올라간 글 열기 ↗** 버튼을 없애고, 글이 올라간 곳의 **링크 주소 자체를 그대로 노출**한다(선택·복사 가능). 클릭하면 기존처럼 기본 브라우저로 열린다.
