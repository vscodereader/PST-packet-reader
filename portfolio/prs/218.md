## Summary
5종목 게시 중 일부만 성공(예: 3개 후 계정 막힘)했을 때, **올라간 글의 실제 내용을 확인**할 수 있게 합니다. 글이 빛삭(게시 직후 삭제)돼도 무엇을 보냈는지 완료 로그에서 확인 가능합니다.

- 종목별로 **토큰 치환된 실제 제목·본문·댓글 + 글 URL**을 완료 로그에 보존(`PostedContent`).
- 알림(🔔) 화면의 각 종목 줄에 **"게시 내용"** 토글 → 펼치면 제목·본문·댓글과 **"올라간 글 열기 ↗"** 링크 표시.
- "5개 중 몇 개 성공/실패"는 종목별 줄로 이미 확인 가능(기존) + 이제 각 성공 글의 내용까지.

## 구현
- `PostedContent{title,body,comment?,url?}` 구조체 + `BatchItem`·`ForumPublishResult`에 `posted`(Optional) 필드.
- `run_one_forum_stock`가 종목별 게시 내용 반환 → `run_forum_publish` → 완료 로그 BatchItem으로 전파.
- 프론트 `data/types.ts`·바인딩·`notifications.tsx` 렌더 추가.
- 새 패킷 불필요(이미 받는 add 응답의 result/id에서 URL 도출). 실패·기존 경로·동작 무변경(additive).
