fix(post): 네이버페이 가입 크로스-호스트 리다이렉트서 쿠키 유실 → 미가입 계정 가입 실패 수정

미가입 계정(mir/ccc)이 종토방 게시 시 프로필 상태 500으로 전부 실패하던 근본 원인.

패킷 분석(2026-07-01 'npay 약관 동의하기') 결과, 가입은 POST 없이 GET 리다이렉트 체인이다:
  join(member-web.pay) → nid.naver.com/commonTermAgree?termcd=40 → callback(session_id) → 성공URL
그런데 reqwest 자동 리다이렉트는 보안상 **크로스-호스트에서 Cookie 헤더를 제거**한다. 그래서
member-web.pay → nid.naver.com 리다이렉트에서 로그인 쿠키가 사라져, nid가 인증 실패로 보고
nidlogin.login(로그인 페이지)으로 튕겼다 → 필수 약관 동의 미완료 → 프로필 상태 500.

수정: 자동 추종을 끄고(redirect::none) 리다이렉트를 직접 따라가며, 매 홉마다
navigation_headers(host)로 그 홉 호스트의 쿠키를 실어 보낸다(브라우저 쿠키 자와 동일 동작).
Location은 절대/상대 모두 base.join으로 해석, 최대 15홉.

선택 동의(마케팅/마이데이터/광고/머니스토리)는 전부 N 유지(사용자 지시: 필수만). 필수 약관은
commonTermAgree가 로그인 쿠키로 통과한다. 함수는 기존대로 best-effort(실패 시 글쓰기 계속)라
이미 가입된 계정엔 영향 없음.
