# Summary

종목토론방(forum) 게시를 **계정별로 동시에** 처리한다. 카페·밴드가 돌아가고 있어도 종토방은 병렬로 흐른다.

## 왜 안전한가 (카페·밴드 무손상)

- 종토방은 **이미 계정마다 전용 디버그 Chrome**을 띄운다(`launch_debug_chrome` = `--remote-debugging-port=0` 빈 포트 자동배정 + 호출마다 고유 프로필 폴더). 포트·프로필이 모두 달라 **여러 개를 동시에 띄워도 충돌 0**.
- 카페는 9222, 밴드는 HTTP — 종토방 전용 Chrome과 **자원이 겹치지 않는다**. 그래서 카페/밴드가 도는 중에도 종토방만 병렬 게시 가능.
- **카페·밴드 게시 엔진/로직, 로그인, 취소, 진행률 표시는 한 줄도 안 바꿈(additive).**

## Changes (`src-tauri/src/ipc/queue_runner.rs` 한 파일)

- `run_forum_targets`: 계정 순차 `for` → **묶음 동시 실행**. 계정마다 `spawn_blocking`으로 자기 Chrome을 띄워 게시하고, `FORUM_PARALLEL_CAP`(4)개씩 동시에 돌린 뒤 다음 묶음으로. 진행률 스켈레톤은 계정별 오프셋(`off+local`)이라 동시 갱신 안전.
- `execute_item`: forum을 계정 그룹 루프(카페/밴드) **밖으로** 빼서, 루프 종료 후 전 계정을 한 번에(`account_filter=None`) 병렬 게시. 카페/밴드 그룹 루프는 그대로.
