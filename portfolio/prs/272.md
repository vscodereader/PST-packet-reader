## 문제
로그인할 때마다 캡차가 뜨는 회귀. 사수 진단: "연결이 제대로 되지 않은 상태에서 로그인 시도하면 100% 캡챠가 뜬다."

## 원인
#267 로그인 단축(5f926a2)에서 `ADB_SETTLE_AFTER_ROTATE_SECS`를 **3→1초**로 줄임. 비행기모드 토글로 IP를 회전한 직후엔 ping이 붙어도 DNS/라우팅·TLS 세션이 아직 자리잡지 않아, 1초 만에 로그인하면 '연결 미완성' 상태 → 캡차.

## 수정
연결 안정화 대기만 **1→3초로 복구**. 의도한 단축(IP 확인 폴링 100ms, 글자별 타이핑 지연 제거, 폼/폴링/settle 단축)은 **그대로 유지** — 사용자가 요청한 타이핑·IP 시간은 빠른 채로 둔다.

검증: auth 테스트 99건 통과. 변경 1줄(config 상수).
