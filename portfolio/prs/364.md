## Summary
- 종토 게시가 특정 계정에서 **프로필 상태 500**(Failed to fetch profile user status)으로 매번 실패. 진단(#363 프로브)으로 **500 ⟺ npay 약관 미완료**가 1:1 확정(헤더·쿠키 아님).
- **근본원인**: 패킷 기반 npay 가입은 미가입 계정에서 nid가 재로그인을 요구해(`join→commonTermAgree→nidlogin.login`) 완료 불가. **브라우저는 로그인 직후 신선한 nid 세션**이라 commonTermAgree의 JS 리다이렉트까지 통과해 가입 완료(실측 캡처 `npay 약관동의`).
- **수정**: 로그인 성공 확정 순간(쿠키 수거 직전) 그 브라우저를 npay 가입 URL로 보내 성공 착지까지 대기 후 쿠키 수거(`harvest_cookies_after_npay`). 폴링 중 세션 확인(`read_signals`)엔 안 써서 로그인 흐름 불변. 이미 가입 계정은 즉시 성공(멱등), best-effort.
- ⚠️ **게시(posting)는 그대로 100% 패킷** — 페이지 이동/로드 대기 없음. 브라우저는 로그인 단계만 사용(ADR-0009와 일관).
