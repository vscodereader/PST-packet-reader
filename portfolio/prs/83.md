## 버그

계정 관리 표에서 **빈 비밀번호 칸을 클릭해도 입력창이 안 떠서** 새 계정에 비밀번호를 넣을 수 없음.

## 원인

`PwCell`의 클릭 버튼이 빈 값일 때 `"•".repeat(Math.min(0,10))` = `""`(빈 내용)을 렌더 → 버튼 높이가 0으로 찌부러져 클릭 타깃이 사라짐. (아이디 칸은 placeholder가 있어 정상.)

## 수정

빈 값일 때 `비밀번호` placeholder(흐린 회색)를 표시해 항상 보이는 클릭 영역이 되도록 함. 값이 있으면 기존대로 마스킹(●) 표시. 동작 외 변경 없음.

fix(accounts): make empty password cell clickable with placeholder

An empty password cell rendered no content ("".repeat(0)), so the edit
button collapsed to zero height and couldn't be clicked — new accounts
could not get a password. Show a '비밀번호' placeholder (dimmed) when empty,
matching the id cell, so the cell is always a visible click target.
