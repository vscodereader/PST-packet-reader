fix(posts): 종토 HTTP 500/서버오류는 재시도 말고 빨리 실패 (통제 불가 네이버 판정)

사용자 지시(2026-06-30): 일시적 네트워크 연결 불안정(소켓 10053/54/60)은 재시도 타협 여지가
있지만, HTTP 500/403 같은 네이버 서버의 판정은 사용자가 통제할 수 없는 문제라 재시도해도 또
실패한다 → 빨리 실패시킨다. #335에서 500을 재시도(9회) 대상으로 둔 것이 의도와 반대였다.

- is_timed_out_failure에서 서버오류(500·"서버에 문제"·"네이버 서버"·"Internal Server") 분기 제거.
  남는 재시도 대상: (1) 페이지/응답 대기시간 초과(로딩 지연), (2) 일시 네트워크 끊김(소켓).
- 500은 차단도 대기초과도 아니므로 errored로 떨어져 즉시 실패(계정 Error 표시).
- 미사용이 된 server_error_http_status 제거.
- 403/401은 기존대로 is_blocking_failure로 빨리 실패(변경 없음).
- 테스트 갱신: 500=비재시도(빨리 실패) / 네트워크 끊김·페이지 로드 초과=재시도.
