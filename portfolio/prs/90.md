## 무엇 (사수 권고: 타이밍/생명주기)

이전 Chrome이 완전히 종료되고 IP가 바뀐 뒤에 새 Chrome을 띄우도록 **순서를 로그로 확인 가능**하게 하고, IP 회전 후 안정화 대기를 추가합니다.

- `ChromeHandle::Drop`: `창 닫힘` → kill+wait로 **프로세스 완전 종료 확인** 로그.
- `launch()`: 디버그 포트 확정(=완전 로딩) 시 로그.
- IP 회전 후 `ADB_SETTLE_AFTER_ROTATE_SECS`(3초) 대기 후 Chrome 실행 + 로그.

순서: 이전 Chrome 완전 종료(로그) → 비행기모드 토글 + IP 변경 확인(로그) → 안정화 대기 → 새 Chrome 실행(로그) → 작업 → 창 닫힘 + 완전 종료 확인(로그).

프로세스 생명주기·관측성만 추가, 로그인 동작 변경 없음. 기존 코드 누락 없음. rust 128 테스트·clippy·fmt 통과.

Closes #89
