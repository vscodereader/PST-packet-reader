## PR 본문 원문

## 배경
release 빌드에서 `MAX_DONE_NOW`/`apply_complete_now`/`prune_done_now`가 `never used`(dead_code) 경고를 냈다. 이들은 #289에서 "완료 작업을 큐에 Done 카드로 남기는" 기능용으로 추가됐다가, #294/#295에서 "큐엔 진행 중만, 결과는 알림에서"로 **되돌리며 호출처가 사라진 잔해**다. 단위테스트만 이들을 붙들어 test 빌드에선 안 떴고 release에서만 경고.

## 변경
- 죽은 항목 제거: `MAX_DONE_NOW`(const), `apply_complete_now`, `prune_done_now`.
- 딸린 단위테스트 4개 제거: `complete_now_keeps_item_as_done_and_preserves_result`, `complete_now_unknown_id_is_noop`, `prune_done_now_drops_oldest_done_beyond_cap_keeping_active`, `prune_done_now_under_cap_is_unchanged`.
- `apply_clear_done_now`("완료 항목 지우기")는 **실제 사용 중이라 보존**.

## 검증
- 사용처 grep 0건(컴파일러 dead_code가 보증). **동작 변화 없음.**
- `cargo test --lib ipc::queue` → 146 passed. 해당 dead_code 경고 3건 해소.
- 남은 2개 경고(`queue_runner.rs:816-817` doc list)는 기존 무관 항목으로 이 PR 범위 밖.

@pallas-dev 죽은 코드 정리입니다.
