# Summary

게시 큐 워커가 **종목토론방 전용 아이템들을 동시에** 처리하게 한다. 큐에 종토방 아이템이 2개 있으면 둘 다 같이 진행된다(각자 진행률이 같이 돌면서 동시 게시).

## 왜 필요했나

#237/#238은 **한 아이템 안의 여러 계정**을 병렬화했지만, 워커가 **아이템 자체는 한 번에 하나씩**만 처리해서, 아이템이 2개면 1번 끝나야 2번이 시작됐다(1번 "처리 중", 2번 "대기"). 사용자가 본 게 이거다.

## 어떻게 (카페·밴드 무손상)

- 워커가 **종토방 전용 아이템**을 만나면 `await`하지 않고 **백그라운드 태스크로 띄워** 곧장 다음 아이템을 집는다 → 종토방 아이템들이 동시에 돈다. 종토방은 계정마다 전용 헤드리스 Chrome이라 카페(고정 9222)·밴드(HTTP)와 자원이 안 겹쳐 동시 안전. 동시 수는 `FORUM_ITEM_PARALLEL_CAP`(4)로 제한.
- **우선순위는 이미 #231에 있음**: `pick_next_waiting`이 종토방을 카페·밴드보다 먼저 집는다 → 대기 중 밴드/카페보다 종토방이 먼저 실행. (사용자 요구: "대기 중 A(밴드)보다 C(종토방) 먼저")
- **카페·밴드·로그인은 한 글자도 안 바꿈** — 자원 공유(9222·폰 IP 로테이션) 때문에 기존대로 순차 `await`. 종토방 전용 아이템만 새 동시 경로.
