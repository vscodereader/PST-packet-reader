데스크톱(코어) — 종토 "게시 후 내용 변경" 동작 개선(#400). Admin 변경 없음.

## 문제
기존엔 `원글 게시 → N초 대기 → edit → 완료`가 한 덩어리로 묶여 로딩바가 전체를 돌고
그 뒤에야 1분 텀이 시작됐다(원글 간격 = 원글+N초+edit). 또 edit는 원글 카드에 조용히
반영돼 눈에 안 보였다.

## 변경
- **edit를 백그라운드 spawn_blocking으로 분리**(`spawn_forum_content_edit`). 원글 게시
  직후 `run_one_forum_stock`가 리턴 → **기존 1분 텀이 원글 시점부터** 시작(수정 전과 동일
  간격, 신규 타이밍 코드 없음). edit는 N초 뒤 저장 쿠키로 새 클라이언트를 만들어 edit_post.
- 수정 완료 시 **"내용 변경" LogBatch 카드**(바뀐 내용 + 원글과 동일 링크) → 알림 패널에
  400ms 폴링으로 표시 + `forum-content-edited` 이벤트로 **토스트**.
- 원글 게시 순간 `forum-content-original` 이벤트로 **토스트**(내용변경 게시에 한함).
- app-shell에 Tauri 이벤트 `listen` 리스너 추가(프론트 최초 이벤트 사용, 전역 event 목).
- 중지/kill해도 예약된 edit는 그대로 실행(사용자 결정).
