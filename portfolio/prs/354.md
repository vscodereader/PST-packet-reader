## 개요
글 관리 페이지 **엑셀 가져오기 옆에 '좋아요' 버튼**을 추가합니다. 누르면 "특정 게시글 댓글"과 같은 **링크 입력 UI를 재사용**해 게시글 링크를 받고, 그 아래에는 댓글 대신 **로그인된 종목토론방 계정을 체크박스(AccountRow 재사용)**로 고릅니다. 링크·계정을 고르고 좋아요를 누르면 선택 계정들이 그 글에 좋아요를 누릅니다 — **페이지 이동 없이 reactions API로만**(사수 지시).

## reactions API (패킷 분석 2026-07-01)
- `GET /api/community/discussion/posts/reactions?postIds=` — 현재 상태(`recommended`·`reactionId`)
- `POST /posts/{id}/reactions` `{"reactionType":"good"}` — 최초
- `PUT /posts/{id}/reactions/{reactionId}` `{"reactionType":"good"}` — 변경(마지막 상태가 표시)
- 로직: 조회 → 이미 좋아요면 skip / `reactionId` 있으면 PUT / 없으면 POST (멱등)

## 변경
**백엔드**
- `NaverPacketClient::from_storage_state` — 저장된 로그인 쿠키(파일)만으로 클라이언트 생성(**Chrome 없이 API 전용**). naver 도메인 쿠키만 수집, `NID_AUT`/`NID_SES` 없으면 실패. UA는 카페 `BROWSER_USER_AGENT` 재사용.
- reactions 메서드(`read_post_reaction`/`create`/`update`) + `like_post`. postId는 기존 `object_id_from_url` 재사용. PUT용 `put_with_retry`(429·5xx 백오프 + 실제 API 로그).
- `run_naver_like(account_id, post_url)` + IPC `like_discussion_post`(계정 순차, 계정 간 1.5초 간격, 계정별 성공/실패).

**프론트**
- `like-modal.tsx`: 링크 입력 + `AccountRow`(계정 체크박스, publish-modal에서 export) 재사용 + 결과 패널.
- `posts.tsx` 툴바 '좋아요' 버튼, `ipc.forum.like`, `Icon.heart` 추가.
