## Summary

- **패킷(`블로그 주소 분석.pcapng`) + 실제 PostView HTML 분석**으로 근본 원인 확인: 현행 네이버 `PostView.naver` HTML에는 **`groupId` 토큰이 아예 없고**, cbox가 쓰는 groupId 값이 **`blogNo = 165657723`** 형태로만 들어 있다. (cbox `groupId` == 블로그 `blogNo`)
- 기존 `parse_group_id`는 `groupId` 토큰만 찾아 **항상 None → "groupId를 찾지 못했습니다" → 댓글 미등록**(특정글·최신N 모드 둘 다 이 경로를 거침). 이게 블로그 댓글이 안 달리던 진짜 이유.
- `parse_group_id`가 `groupId`(구버전) → `blogNo`(현행) 두 토큰을 차례로 찾도록 수정. 공통 추출은 `find_number_after_token`로 분리(모든 출현 검사, 숫자 없는 출현 건너뜀).
- **검증**: 실제 `secretcc1205/224324998070` PostView HTML에서 `165657723` 추출 = 패킷의 cbox groupId와 일치. objectId(`{groupId}_201_{logNo}`)·토큰/생성 URL은 패킷과 이미 일치(변경 없음).
