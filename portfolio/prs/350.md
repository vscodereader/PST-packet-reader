## 변경
### 1) 동의하기 패킷 복원
패킷 분석상 "동의하기"는 체크박스가 아니라 **가입 URL로 가는 GET 리다이렉트 체인**(`financial-service/join?consent=N` → 302 → 약관동의 → 콜백 → 가입 완료)이다. 로그인 쿠키를 든 패킷 클라이언트로 그 URL을 GET(리다이렉트 추종)하면 가입이 끝난다.
- `packet_client.ensure_npay_financial_join()` 추가, `open_discussion_session`의 로그인 확인 직후(옛 `ensure_discussion_page` 자리)에서 1회 호출.
- **이미 가입된 계정**: 성공 콜백으로 리다이렉트 = 무해(멱등). **미가입 계정**: 가입 완료. 선택 동의(마케팅/마이데이터/머니스토리)는 전부 N 거절.
- 비치명적(전송 실패해도 글쓰기는 시도), 최종 URL·status를 로그로 남겨 가입 완료 여부 진단.
- 테스트: `.naver.com` 로그인 쿠키가 pay 호스트에 붙음 / 최종 URL 가입 완료 판정.
