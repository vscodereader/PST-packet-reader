## 요약
네이버 밴드(band.us) **가입·글쓰기·댓글을 순수 HTTP(패킷분석)** 로 구현했습니다. 사수 지시(CDP 폐기, 전부 패킷분석)에 따라, 카페·종토방과 동일하게 Rust에서 직접 요청을 만들고 서명해 전송합니다. 별도 모듈 `src-tauri/src/band_post/`로 추가하며 기존 `band_auth`/`naver_cafe` 동작은 무수정(additive)입니다.

추가로(2026-06-09) **밴드 게시 결과 로그(✅/❌)** 와 **밴드 게시 결과를 알림(게시 배치)에 기록**하는 연결을 더해, 종토방처럼 밴드도 알림에서 결과·작성 내용을 확인할 수 있게 했습니다.

## 핵심 돌파구 — `md` 서명 역공학 (캡처 3/3 검증)
`api-kr.band.us` 요청은 `md`(message digest) 헤더 서명을 요구합니다. 자체 3계정 패킷 캡처 + band-web JS(`BandWebAuthModule.makeMd`, sjcl HMAC) 분석으로 알고리즘을 해독하고, **캡처에 담긴 실제 secretKey로 실제 md 3개(join/post/comment)를 Rust에서 바이트 단위로 재현해 검증**했습니다.

```
md = base64_standard( HMAC-SHA256( key = utf8(secretKey), msg = path+query ) )
secretKey = GET auth.band.us/s/login/getKey (쿠키인증 JSONP) 응답의 세션 동적값(로테이션)
akey(bbc59b0b…) = 고정 APP_KEY(헤더값, HMAC 키 아님)
```

## 구현 (`band_post/`, 모두 TDD)
- `signature` — md(HMAC-SHA256) 서명. **캡처 실측 md 3개를 ground truth로 검증**
- `getkey` — getKey JSONP 파서(secretKey/isJwtType), Debug에서 redacted
- `request_builder` — join/post/comment 폼바디·헤더. serde_urlencoded 출력이 캡처 바디와 일치
- `client` — reqwest(getKey→서명→POST), wiremock으로 md/akey/Cookie 전송·result_code·HTTP 오류 검증
- `cookies`/`link`/`response`/`error` — band.us 쿠키 필터, band_no 링크 파서, result_code/post_no 파싱
- `band_publish` 오케스트레이션 — 링크→가입(best-effort)→글 게시→선택 댓글
- IPC `band_publish` 등록(lib.rs)

## 프론트 (게시 모달)
사용자 흐름대로: 밴드 선택 → **가입 링크 입력 + 저장 버튼** → 게시 시 그 링크로 가입 후 제목·내용 게시. 저장된 링크가 없으면 게시 버튼 비활성(조용한 실패 방지). 시뮬레이션을 실제 `band_publish` 호출로 교체.

## 추가 (2026-06-09) — 게시 결과 로그 + 알림 기록
- **게시 결과 로그(✅/❌)**: 밴드 로그인은 `[BAND] ✅/❌ 로그인 …` 결과 로그가 있었으나 게시는 단계 로그만 있어, 종토방(`… 글+댓글 성공 ✅`)처럼 최종 결과 라인이 없었다. `band_publish`를 얇은 래퍼로 감싸 성공 시 `[BAND] ✅ "{밴드}" 글(+댓글) 게시 성공 …`, 실패 시 `[BAND] ❌ 게시 실패 — 계정 … (오류)`를 남긴다. 성공 문구는 순수 함수(`publish_success_log`)로 분리해 테스트.
- **알림 기록**: 종토방만 백엔드(`run_forum_publish_now`)에서 LogBatch를 남겨 알림에 떴고 밴드는 결과만 프론트로 돌려줘 알림에 안 떴다. 백엔드에 `record_band_batch` 커맨드(platform: Band 배치 + activity 저장)를 추가하고, 프론트(publish-modal)가 모든 밴드 잡을 마친 뒤 결과를 모아 한 번 호출한다. 기존 게시 흐름·종토방 배치 기록은 불변(additive).

**추가 변경 파일**: `src-tauri/src/band_post/mod.rs`(결과 로그), `src-tauri/src/lib.rs`(`record_band_batch` 커맨드 + 등록 + `band_batch_kind` 헬퍼), `src/shared/ipc/index.ts`(`ipc.band.recordBatch` 파사드), `src/features/posts/publish-modal.tsx`(밴드 게시 후 호출), `src/test/ipc.ts`(목 핸들러).
