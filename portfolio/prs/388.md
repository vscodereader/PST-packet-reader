## 배경
7/3 실기기 로그+패킷(`실명인증.pcapng`) 분석 결과:
- **실명인증 미완 계정**: 우리 패킷 흐름은 프로필 생성 POST **500 `Failed to create profile user`**를 받음. 브라우저는 같은 계정에서 `nid.naver.com/user2/help/realNameCheck`(실명확인 폼)로 튕김 → **실명인증 필요 확증**. (`isNiConnected`는 성공 계정도 false라 판정 불가 → 폐기)
- **차단 계정**: 글쓰기 form **403 `UMON_PERMANENT_BANNED`**(네이버 원문).

## 변경 (사수 지시 반영)
1. **실명인증 판정** — 프로필 생성 500 뒤 `realNameCheck.nhn`을 쿠키 달아 한 번 GET해 실명확인 폼이 오면 확정 → **로그인 실패와 동일 처리**: 상태 **Error** + 사유 **"권한이 없거나 로그인이 만료되었습니다"** + 게시 목록 숨김(Error는 POSTABLE 아님).
2. **차단 원문** — 네이버가 직접 쏜 차단(UMON/403F01)은 우리 일반 문구로 덮지 말고 **네이버 원문 그대로** 표시.
3. **죽은 계정 쿠키만료 숨김** — Active였다가 게시 중 차단/에러로 죽은 계정은 세션 쿠키 삭제 → 쿠키만료 카운트다운 사라짐(좋아요 흐름과 동일).
