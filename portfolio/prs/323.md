fix(auth): [진단] 수동입력 모드 — 환경(CDP/플래그) vs 합성입력 원인 격리

지문 A/B로 IP·브라우저지문·CDP콘솔탐지·headless·DOM타이밍을 전부 배제한 뒤에도(같은 폰
IP·동일 지문) 매크로만 캡차. 남은 차이는 (1)CDP가 띄운 크롬 환경/플래그 (2)합성 입력(행동데이터)
둘뿐이라, 이 둘을 가르는 진단 모드를 넣는다.

- 환경변수 PSTMACRO_LOGIN_MANUAL 설정 시:
  - login.rs: headless 강제 off(headed) — 사용자가 창을 보고 직접 입력
  - login_flow.rs: navigate + 폼 완전 로딩 대기까지는 그대로 하고, 자동 타이핑/클릭을 생략하고
    manual_login_wait()로 세션 쿠키를 최대 180초 폴링(캡차 감지 시 로그)
- 같은 CDP 크롬에서 손입력=성공 → 원인은 합성 입력(행동데이터), 손입력에도 캡차 → 원인은
  환경(CDP/플래그). 기본 off라 평상시 동작 무변경.
