- `scripts/setup-gcp-cloud-run.sh` — 원타임: Artifact Registry·배포SA·WIF·시크릿 3종(database-url/jwt-secret/enc-key).
- `scripts/setup-cloud-sql.sh` — 원타임: Postgres 인스턴스+DB+DATABASE_URL 시크릿 자동등록.

- 단일 서비스/인스턴스(dev/prod 분리 없음).

`--min-instances=1 --max-instances=1 --no-cpu-throttling --timeout=3600 --session-affinity` — SSE 허브·인메모리 상태·예약 스케줄러가 인스턴스별이라 1개 고정 + CPU 항상 할당.
