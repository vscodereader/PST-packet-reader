## 무엇을
종목토론방 '특정 게시글' 댓글이 성공하면 알림 → '게시내용'에 **댓글 내용만** 보이고 어느 글에 달았는지 **링크가 없었다**. 이제 단 글의 URL도 함께 보인다.

## 왜
댓글 전용 결과의 `PostedContent.url`이 `report.post_url`(댓글 리포트는 None)이라 비어 있었다.

## 어떻게
- `comment_detail_url` 헬퍼 추가: `comment_url`(특정 글 URL)이 있으면 그 URL을 '게시내용' 링크로 싣고, 없으면 기존대로 `report.post_url`로 폴백(랜덤 글 댓글은 None 유지).
- 프론트 알림 상세는 이미 `posted.url`을 댓글과 **별개의** Anchor로 렌더 → 댓글+링크가 함께 보인다(프론트 변경 없음).

## 테스트
- Rust 단위 테스트: 특정 URL 우선 / 공백 comment_url 무시 폴백 / None 유지.
- `cargo test --lib discussion_batch` 통과.
