2. **로그인 폼 대기**: 폼 DOM 준비 즉시 진행(폴링 250→100ms, 상한 10초 무한대기 방지용 유지).
3. **ID/PW 입력 사이**: 800→100ms.
4. **결과 폴링**: 고정 400→100ms로 결과 DOM 자리잡는 즉시 진행.

유지(건들면 안 됨): IP 회전 후 **연결 안정화 3초**, 클릭 후 settle 0.8초.

검증: auth 테스트 100 통과 / clippy 깨끗.
