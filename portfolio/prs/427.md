## 원인 (수동 vs pstmacro 패킷 겹쳐 확정)
`/api/report`의 ncaptchaTokenId는 ncaptcha SDK가 **제출 순간 WASM으로 생성**하는 캡차 토큰 — JS 변수로 스크랩 불가. 그래서 로그인된 CDP 브라우저가 **실제 사용자처럼 제출**하게 재설계.

- content_resolver: 전체 신고 URL 조립(cid/cwriterenc/ctitle/cnickname).
- token.rs → ReportBrowser: 전체 report URL 이동 → 사유 선택 + 제출 버튼 클릭(라이브 DOM 탐색·전부 로깅) → 페이지가 자체적으로 토큰 생성 + /api/report POST.
- CdpClient: Network 캡처로 페이지의 /api/report 요청 본문(진짜 ncaptchaTokenId)·응답({"success":true}) 포착.

**국내주식만 대상**(해외주식 제외 — 사용자 확인).

## ⚠️ 실기기 검증 필수

fix(report): drive real page submit for ncaptcha token instead of scraping

The ncaptchaTokenId in POST /api/report is a WASM-generated anti-bot captcha
token the ncaptcha SDK produces only at real submit time — it never exists as
a JS variable to scrape (confirmed by overlaying manual vs pstmacro packets
2026-07-14). So let the logged-in CDP browser submit exactly like a user:

- content_resolver: resolve_target() now returns encryptedUserId + display-only
  title/nickname (from the by-item post's `title` / `writer.nickname`), and
  build_report_page_url() assembles the full verified report-page URL with the
  measured param order + application/x-www-form-urlencoded encoding.
- token.rs → ReportBrowser: navigate the full report URL, wait for the SPA +
  /api/reason to render the reason UI, select the reason (by code attribute or
  label text) and click the primary submit button via Runtime.evaluate — both
  scripts search the live DOM generically and log everything found/clicked.
- naver_automation CdpClient: NetworkCapture + arm_network_capture /
  wait_for_network_capture / network_get_response_body, mirroring the existing
  record_network_event pump, to capture the page's own POST /api/report request
  body (reveals the real ncaptchaTokenId) and response ({"success":true}).
- report_client: drop the now-dead reqwest /api/report submit + body builder
  (the page posts itself); keep by-item/profile GETs. Add reason_label().

Heavily instrumented: one live run logs the navigated URL, rendered reason DOM,
exact clicked elements, and the raw /api/report request + response bodies.
