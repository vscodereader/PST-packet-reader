## Summary

- 같은 하위 PC를 재등록/재설치해도 **같은 기기 1개**로 인식(§E 설계). 등록마다 새 랜덤 UUID로 기기가 늘어나던 문제 해결.
- **A. 컴퓨터 이름**: 하위 앱이 등록 시 `COMPUTERNAME`(폴백 hostname)을 name으로 전송(서버는 이미 `req.name` 존중).
- **C. machine_id upsert**: 하위 앱이 Windows MachineGuid(비Windows `/etc/machine-id`)를 `machine_id`로 전송 → 서버 `register_device`가 machine_id로 기존 기기를 찾으면 같은 `device_id` 재사용·이름/last_seen 갱신·토큰 재발급(새 row X). nullable → 옛 앱/옛 row 하위호환.
