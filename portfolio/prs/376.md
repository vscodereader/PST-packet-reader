fix(login): visibilityState=hidden 로 키 이벤트 드롭되던 문제 해결

원인 확정(2026-07-02 사수 PC/Chrome 원격 데스크톱 로그): 창이 가려져
document.visibilityState=hidden 이 되면 Chrome 이 합성 키(Input.dispatchKeyEvent)를
렌더러로 전달하지 않고 버린다. 계기판 로그가 recorder_selftest=1·cdp_dispatched=18·
keydown=0·vis=hidden 으로 증명(마우스는 좌표라 먹혀 포커스는 잡히나 타이핑 0자).
같은 실행에서 창이 안 가려진 계정은 성공 → 간헐성도 일치.

- chrome.rs: --disable-backgrounding-occluded-windows / --disable-renderer-backgrounding
  / --disable-background-timer-throttling 추가 — 가려진 창의 렌더러 백그라운딩을 꺼
  창이 전경이 아니어도 키가 전달되게 한다(핵심 수정).
- login_flow.rs: force_page_foreground() — 타이핑 직전 Page.bringToFront +
  Emulation.setFocusEmulationEnabled(true)로 전경·포커스 강제(방어적 2차 안전장치).

둘 다 best-effort(실패해도 로그인 진행). 검증: cargo check OK.
