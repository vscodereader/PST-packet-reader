## 문제 (실측 2026-06-30)
한 종토 배치에서 다른 6계정은 정상인데 **jaj 계정만** 종목마다 이 500을 맞았다:
\`\`\`
프로필 상태 패킷 HTTP 실패: status=500, body={"message":"Failed to fetch profile user status"}
\`\`\`
코드가 이 500을 **일시 서버오류(대기초과)로 보고 종목당 최대 30회(백오프 30초) 재시도** → 한 계정이 배치를 **수십 분** 붙잡고(10:41~11:01+ 계속 재시도), 결국 다 실패. 같은 계정만 매번 이 500이면 서버 부하가 아니라 **그 계정의 지속 문제**(제재·본인인증 미완·잠금 등)라 재시도해도 또 실패한다.

## 변경
- \`is_profile_status_unavailable()\` — 본문 \`Failed to fetch profile user status\` 감지(순수 함수)
- \`is_timed_out_failure()\` — 이 메시지엔 **false** 반환 → \`is_retryable_forum_failure=false\`라 **즉시 실패(재시도 0)**
- **일반 일시 500**(서버 부하)은 그대로 재시도 대상 유지 — regression 방지
- 계정은 차단·대기초과가 아니므로 **Error**로 칠해진다(활성으로 안 남음 → 앞서 "실패했는데 활성" 문제도 해소)

## 검증
- \`cargo test --lib discussion_batch\` → 10 passed (신규 테스트: 프로필 500=비재시도 / 일반 500=재시도 유지)
