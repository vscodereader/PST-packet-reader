fix(ui): refresh sidebar badge counts on navigation

Badge counts (글 관리/게시 큐/계정 관리) were loaded once on mount, so they
stayed frozen after adding/deleting accounts, posts, or queue items. Extract
the load into refreshCounts and call it on every navigation (go) as well as on
mount, so the badges reflect the current counts. Count computation unchanged.

Closes #91
