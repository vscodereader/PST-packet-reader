## 개요
글 관리 툴바에 **조회수** 버튼을 추가한다. 순서: `엑셀 가져오기 → 조회수 → 좋아요 → 싫어요 → 글쓰기`.

## UI (`view-count-modal.tsx`)
좋아요 모달 UI 재사용:
- 게시글 링크를 칩으로 여러 개 입력(엔터/추가)
- 공용 **반복 횟수(N)** 숫자 필드(1~1000)
- **링크 1개↑ + N≥1** 이면 `조회수` 버튼 활성화(숫자칸 비우면 비활성)
- `닫기` / `조회수` 버튼, 링크별 성공/진행 결과 패널

## 동작 (`view_boost.rs`)
각 링크를 시크릿창으로 N번 **순차** 반복:
1. `launch_debug_chrome(false)` — 보이는 incognito·고유 임시 프로필
2. 링크 이동 → **`readyState=complete` 완전 로딩 대기**(navigate는 interactive에서도 반환하므로 한 번 더 조임)
3. `Page.reload` → 다시 완전 로딩 대기
4. `ChromeHandle` Drop → **그 창의 프로세스 트리만** `taskkill /PID /T /F` + `wait()` 회수 + 임시 프로필 삭제. 창을 완전히 닫은 뒤에야 다음 회차를 열어 **고아 프로세스 없음**

링크 하나가 실패하면 그 링크는 거기서 멈추고 다음 링크로 진행. `boost_view_count` 커맨드가 링크 trim·빈값 제거·N≥1 검증.

## 무손상 원칙
기존 `launch_debug_chrome`·`CdpClient`를 **호출만**(읽기 재사용). 로그인·좋아요·카페·블로그·밴드 등 기존 코드는 한 줄도 수정하지 않음. 공유 파일 `lib.rs`는 모듈 선언·커맨드·핸들러 등록 3곳만 추가.
