## PR 본문 원문

## 증상
ID·PW를 다 넣었는데도 `로그인 폼 자동 입력에 실패했습니다(비밀번호 칸이 비어 로그인을 중단)`.
표준문자 비번(예: `ghkrudslasla36!!!!` — 영문소문자+숫자+`!`)에서도 발생. PW에 3번 입력 시도
후 실패.

## 원인 (타이밍 race, 키 매핑 아님)
`type_into`가 키 이벤트로 타이핑한 **직후 곧장** `el.value.length`로 검증하는데, #267에서
글자 사이 지연을 없앤 뒤로 **긴 비번(18자)을 zero-delay로 연타**하면 네이버 keydown 암호화
훅이 마지막 글자들을 반영하기 전에 읽혀 → 길이가 짧게 나옴 → 3회 재시도 모두 같은 race로
실패 → 정상 입력을 "빈 칸"으로 오판하고 포기.

## 수정
- 타이핑 직후 **검증 전 180ms 정착 대기**(입력칸이 모든 키 반영할 시간)
- 첫 시도는 기존대로 **지연 0**(빠름·리듬 지문 제거 유지), **재시도(2·3회)부터 글자마다 35ms**
  지연으로 누락 복구
- 키 매핑(`key_info`)은 변경 없음 — 원인은 타이밍

## 검증
