# Summary

계정 관리 화면의 **'선택 로그인 (N)'** 버튼 숫자가, 실제로 화면에 체크된 계정 수보다 크게 뜨던 문제를 고친다. 이제 **현재 행에 실제로 존재하는 선택분만** 센다.

## 왜 필요했나

선택 목록(`sel`)을 비우는 경로는 **일괄 삭제 단 한 곳뿐**이라, **행 단위 삭제(휴지통)·로그인 후 행 갱신** 등으로 계정이 사라져도 그 id가 `sel`에 **유령으로 남았다**. 라벨은 `sel.length`를 그대로 썼기 때문에, 화면엔 체크박스 3개만 보이는데 버튼은 `(5)`처럼 표시됐다(사용자: 5개 추가→1·2 실패·3·4·5만 선택했는데 `(5)`로 표시).

## 어떻게 (다른 동작 무손상)

- 파생값 `selPresent = sel ∩ 현재 행 id` 하나를 추가하고, **버튼 라벨과 노출 게이트(`forumOnly`)만** 이 값으로 바꿨다.
- 게시·로그인(`runLogin`)·삭제(`removeSel`)·체크박스 토글 로직은 **한 줄도 안 바꿈** — 이들은 원래도 `rows` 기준으로 한 번 더 거르므로 동작 동일. **카운트 정확도만 보정**한다.

## Changes (`src/features/accounts/accounts.tsx` 한 파일)

- `selPresent` 파생값 추가 → 라벨 `선택 로그인 ({selPresent.length})`, `forumOnly` 게이트가 이 값을 사용.
