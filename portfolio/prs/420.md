## 무엇을 고쳤나 (패킷 실측 기반, 추측 없음)
블로그_기능테스트 패킷을 전수 복호화해 실제 브라우저 요청과 대조하고, 실측대로만 고침.

### 1) 사진·링크·스티커·파일이 안 되던 원인 = se-authorization 토큰
- SeOptions 직전에 **글쓰기 폼을 먼저 열어야**(HTTP GET, 크롬 아님) 서버가 세션쿠키(JSESSIONID/BUC)를 심고, 그래야 토큰(`result.token`)이 나온다.
- 공용 reqwest 클라이언트엔 쿠키 저장소가 없어 워밍업 Set-Cookie를 직접 병합(`CookieJar`). 워밍업 없이는 SeOptions가 "게시물이 삭제되었거나…" 에러 HTML만 반환 → 401.

### 2) 업로드 엔드포인트/파트 실측 수정
- 사진·파일 모두 `POST /api/blogpc001/v2/upload/file`, multipart 파트 `userId`+`file`.
- 사진의 `photo-uploader/upload?sessionKey=` 는 추측 스텁이라 제거. 사진 응답 스키마 확정 전이라 응답 **원문 전부** 로그.

### 3) 블로그 자동생성
- `naverId`=로그인 계정, `domainId`=블로그명(서로 다름) + `X-Requested-With: XMLHttpRequest`(없으면 응답 `null`).

### 4) 편집기 빈칸 UX
- 삽입 시 빈 문단 중복 생성 제거(뒤 문단 재사용), 문단 삭제 버튼, 연속 빈 문단 접기.

### 5) 발행 알림
- 성공 알림에 블로그 링크 동봉 + 자동닫힘 해제(성공/실패 원문 유지).
