## 근거 (지문 A/B 실측, 2026-06-29)
같은 계정: **손 로그인(정상 크롬)=성공, 매크로=캡차.** 두 지문이 딱 **두 필드**만 달랐다:

| 필드 | 정상 크롬(성공) | 매크로(캡차) |
|---|---|---|
| `webdriverOwn` | **false** | **true** |
| `languages` | `ko-KR,ko,en-US,en` | `ko-KR` |

나머지(webdriver, headless, chrome, plugins, GPU, **cdpConsoleTrap**)는 전부 동일 → CDP/headless는 무죄.

## 원인
기존 스텔스 `Object.defineProperty(navigator,'webdriver',…)`가 **인스턴스에 직접** 박아 `navigator.hasOwnProperty('webdriver')===true` → 일반 크롬(프로토타입에만 존재, own=false)과 다른 **탐지 흔적을 스스로 생성**. webdriver 값을 숨기려다 숨긴 흔적을 노출한 꼴.

## 변경
- `STEALTH_INIT_JS`를 `Navigator.prototype`에 정의 → 값·위치·own=false 까지 정상 크롬과 동일
- `languages`도 prototype에 4개 배열로 정렬(빈 incognito 프로필의 1개 현상 제거)
- 게이트/입력/CDP enable 경로 불변. 사수 stealth 방향(ADR-0010) 연장선.

fix(auth): 스텔스를 Navigator.prototype에 정의 — webdriver own-property 탐지 흔적 제거

지문 A/B 실측(2026-06-29): 같은 계정 손 로그인(정상 크롬)=성공, 매크로=캡차인데 둘이
딱 두 필드만 달랐다 — webdriverOwn(정상 false / 매크로 true), languages(4개 / 1개).

기존 스텔스는 `Object.defineProperty(navigator,'webdriver',…)`로 **인스턴스에 직접** 박아
`navigator.hasOwnProperty('webdriver')===true`가 됐다 = 일반 크롬(프로토타입에만 존재 →
own=false)과 다른 탐지 흔적을 스스로 남김(naver wtm이 한 줄로 판별 가능). 즉 webdriver 값을
숨기려던 스크립트가 숨긴 흔적을 노출.

- STEALTH_INIT_JS: navigator 인스턴스가 아니라 Navigator.prototype 에 webdriver(get→false)를
  정의 → 값(false)·위치(proto)·own=false 까지 일반 크롬과 동일하게 정렬
- languages 도 prototype 에 ['ko-KR','ko','en-US','en'] 로 맞춰 빈 incognito 프로필의 1개뿐
  현상을 정상 크롬과 동일화(인스턴스 own 흔적 없이)
- 게이트/입력/CDP enable 경로는 불변. 사수 stealth 방향(ADR-0010) 연장선.

다음 로그의 🕵 지문에서 webdriverOwn:false / languages 4개로 바뀌면 적용 확인.
