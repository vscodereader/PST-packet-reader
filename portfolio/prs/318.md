## PR 본문 원문

네이버 클립(clip.naver.com) 댓글 기능 신규. 블로그처럼 네이버 저장 쿠키를 재사용하되, **댓글 전 클립 프로필 생성(SignUp)** 이 1회 필요해 게시 직전 계정마다 보장합니다. **패킷 분석(`네이버 클립.pcapng` TLS 복호화)으로 확정한 API만** 사용했습니다.

## API (패킷 확정)
- **댓글**: cbox 공유 — `ticket=clip&pool=cbox8`, objectId=미디어 HEX, groupId 빈값. 토큰 GET → create POST(`code:"1000"`).
- **목록**: `POST clip.naver.com/api/graphql` `ContentsQuery`(필요 필드만) → `data.contents.edges[].node.id`.
- **handle→profileId**: `GET clip.naver.com/@<handle>` HTML에서 `"clipId":"<handle>","profileId":"<PID>"` 파싱.
- **프로필**: `GET creatorhub-api/api/v1.0/clip/profiles`(x-creator-hub-sid:clip, code 0=있음/-2102=없음) → `NaverProfile` → `SignUp` mutation.

## 백엔드 (`naver_clip/` 신설, ADD ONLY)
- error/headers/comment_client/clip_list/profile/mod. 카페·블로그·밴드·종토방 **무손상**.
- 큐 연결: `PlatformId::Clip`, `ClipTarget`, `PublishPlan.clip`, `run_clip_targets`(프로필 보장→handle 해석→최신 N개 댓글), group/build_items/build_log_batch/estimate_total/resolved_count 통과.
