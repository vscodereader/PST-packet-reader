## PR 본문 원문

게시큐 상세 펼침이 **안 눌러도 자동으로 펼쳐지고, 하나 누르면 같은 상태("준비하고 있어요") 항목이 전부 펼쳐지던** 버그(사용자 지적 2026-07-01).

## 원인
펼침을 `expandedId === q.id`(**id만**)로 판정 → 실행중 항목의 `id`가 비거나 겹치면:
- 초기 `expandedId=null` 과 `null===null` → **안 눌러도 펼쳐짐**
- 같은/빈 id 여러 개 → **하나 누르면 전부 펼쳐짐**

"준비하고 있어요"(= `items` 비어있는 실행중 항목)들이 이 증상을 보였습니다.

## 수정
펼침 판정을 **행 고유 키(`${id}::${index}`)** 로 변경. 인덱스가 섞여 행마다 항상 고유하므로, id가 비거나 겹쳐도:
1. 초기엔 아무것도 안 펼쳐짐
2. 내가 누른 **그 행 하나만** 펼쳐짐

React key도 rowKey로 바꿔 중복 id 경고 제거.

## 회귀 테스트
빈 id 실행중 항목 2개 → 클릭 전 자동 펼침 0개, A 클릭 시 준비 안내 정확히 1개 (구코드에선 2개가 떠 실패).

## 참고 (정직하게)
현재 큐 아이템 생성 경로(publish/split)는 모두 고유 id를 씁니다 — 빈/중복 id의 정확한 발생 지점은 못 찾았습니다. 이 수정은 **원인과 무관하게** 펼침을 행 단위로 못박아 증상을 원천 차단하는 방어적 수정입니다.
