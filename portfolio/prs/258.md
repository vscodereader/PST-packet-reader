## PR 본문 원문

## 무엇을
밴드에서 댓글작성 → **특정 게시글**(url) + 밴드 글 링크를 넣으면, **밴드 선택 없이** 그 링크의 글에 바로 댓글을 단다. 게시 버튼도 즉시 활성화된다. (종토방·카페에 이어 밴드까지 '특정 게시글' 댓글 지원.)

## 패킷 불필요
밴드 댓글 API `create_comment(band_no, post_no, …)`가 이미 구현·사용 중이고, 필요한 **band_no + post_no가 글 URL** `band.us/band/{band_no}/post/{post_no}`에 다 들어있다. **새 패킷 캡처 없이** 기존 함수 재사용 + 배선만으로 구현.

## 왜 (기존)
밴드만 url 모드에서 의도적으로 제외돼 있었다(`bandUrlUnsupported`로 plan에서 빼고, 워커도 url→latest로 폄).

## 어떻게
- `parseBandPostUrl`: `band.us/band/{bandNo}/post/{postNo}` → {bandNo, postNo, url}. `/post/` 없는 밴드 홈 링크는 null(오대상 방지).
- publish-modal: band+comment+url이면 밴드 계정마다 잡 1개(link=글 URL, board=댓글), '밴드 선택' 요구 면제, `commentReady`에 bandUrlTarget 인정, plan에 밴드 url 대상 포함(기존 제외 해제), `bandCommentSpecFor`가 url이면 `mode=url` 동결.
- band_post: `post_no_from_link` + `band_comment_on_post(account, post_url, comments)` — 피드 조회 없이 URL의 post_no에 `create_comment`(기존 클라이언트 재사용, 단일 대상에 목록 댓글과 동일 분배·베스트에포트).
- queue_runner `run_band_targets`: `comment_target.mode==Url`이면 `band_comment_on_post`로 라우팅(아니면 기존 latest/popular).

## 무손상
최신글/인기글 밴드 댓글, 글/글+댓글, 카페/forum 동작 **무변경**.

## 테스트
- TS: `parseBandPostUrl` 3케이스, 밴드 url 게시버튼 활성·plan 동결(link+`mode:url`).
- Rust: `post_no_from_link`(있음/없음).
