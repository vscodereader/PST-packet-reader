# PSTMACRO 관련 작업 대화

관련 작업 대화의 최신 결과·결정을 확인하고 Git·PR·설계서에 대조함. 대화 전체 원문을 전수 분석했다고 의미하지 않으며 실제 코드·PR 상태가 과거 답변과 다르면 수집 시점 상태를 우선함.

- PSTMACRO Notion 문서화 대화: 사용자가 Wireshark·TShark와 TLS key log를 사용하여 GET·POST 요청을 관측한 개발 과정을 설명함.
- 기존 packet_copy 추출 기록과 실제 Cargo·Rust 코드의 역할을 구분하여 기술 적용 설명을 보완함.
- pstmacro 작업 대화에는 밴드 로그인 패킷 분석 관련 내용이 있음. 비밀키·쿠키 원문과 운영 계정 값을 새 문서에 게시하지 않음.
